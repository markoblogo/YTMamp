INSTALLATION & USAGE GUIDE

Getting Started

1. The Desktop App

The core of the system is the YTMamp desktop application.

  • Install the DMG and drag the app to your Applications folder.
  • Launch the app. It will appear in your macOS Menu Bar (at the top right).
  • The window can be shown/hidden by clicking the menu bar icon.

2. The Chrome Extension

The extension allows the desktop app to control YouTube Music.

  • Open YouTube Music in a Chrome tab.
  • The extension will try to connect to the desktop app automatically.
  • Important: "Auto-connect" only establishes the link; it does not start the desktop app. You must launch the app manually.

3. Usage Tips

  • Tray Icon: Right-click the menu bar icon to enable "Start at login".
  • Window Close: Clicking the 'X' button hides the player to the tray, it doesn't quit the app.
  • Auto-show on play: The player will automatically pop up when you start music in Chrome (can be disabled in settings).
